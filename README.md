# InGit - Integrated Git Platform

> Offline-first система управления версиями, проектами и документацией

## 🎯 Что такое InGit?

**InGit** (Integrated Git) — это комплексная платформа, объединяющая:
- 🔄 **Систему контроля версий** (Git)
- 📋 **Управление проектами** (PM с Kanban/Gantt)
- 📚 **Управление документацией** и знаниями
- 💰 **Финансовый учет** проектов
- 🔐 **Встроенное шифрование** данных

### Ключевая особенность: Полноценная работа в оффлайн-режиме

В отличие от GitHub, GitLab, Jira и других облачных решений, **InGit работает полностью автономно** на вашем компьютере или домашнем NAS.

## 🌟 Основные преимущества

### ✅ Offline-First
Полный функционал без интернета — работайте где угодно

### ✅ Privacy-Focused
Ваши данные хранятся локально, не в чужом облаке

### ✅ Unified Platform
Код + Задачи + Документы + Финансы в одном месте

### ✅ Git Native
История всех изменений, включая метаданные и задачи

### ✅ NAS-Optimized
Идеально подходит для домашнего/малого бизнеса

### ✅ Open Source
Прозрачность, контроль, безопасность

## 🎨 Концепция

### Структура проекта InGit

```
project-name/
├── 00_inbox/              # Временные файлы
├── 10_profile/            # Информация о проекте/команде
├── 20_timeline/           # Журнал событий
├── 30_documents/          # Официальные документы
├── 40_finance/            # Финансы (зашифрованы)
├── 50_projects/           # Исходный код
├── 60_configs/            # Конфигурации
├── 70_tasks/              # Задачи (markdown + YAML)
├── 80_wiki/               # База знаний
└── 90_exports/            # Выгрузки из внешних систем
```

### Метаданные как код (YAML)

Все структурированные данные хранятся в YAML-файлах и версионируются вместе с кодом:

```yaml
# 70_tasks/task-042.yaml
type: task
title: "Реализовать аутентификацию"
status: in_progress
assignee: ivan.petrov
priority: high
estimated_hours: 16
labels: [backend, security]
```

### Умные Git Hooks

Автоматическая валидация и обработка:
- ✅ Проверка обязательных полей в YAML
- ✅ Блокировка коммитов больших файлов
- ✅ Автоматическое закрытие задач через commit messages
- ✅ Шифрование критичных папок

## 🏗️ Архитектура

### Режимы развертывания

#### 1. Standalone Desktop
Полностью автономная работа на одном компьютере

#### 2. Домашний NAS
Централизованное хранение с доступом через локальную сеть

#### 3. Гибридный
Локальная копия + синхронизация с NAS/облаком

### Технологический стек (планируемый)

| Компонент | Технология |
|-----------|------------|
| **Backend** | Python 3.11+ (FastAPI) |
| **Git** | pygit2 (libgit2) |
| **База данных** | SQLite / PostgreSQL |
| **Desktop GUI** | Electron + React + TypeScript |
| **Web UI** | React SPA |
| **Шифрование** | age / SQLCipher |

## 🚀 Roadmap

### Фаза 1: MVP (3-6 месяцев)
- Базовая Git-функциональность
- Desktop GUI (read-only)
- SQLite БД для метаданных
- YAML-валидация через hooks

### Фаза 2: Alpha (2-3 месяца)
- Управление задачами
- Kanban-доски
- Многопользовательский режим

### Фаза 3: Beta (3-4 месяца)
- NAS-сервер
- Синхронизация
- Финансовый учет
- Веб-интерфейс

### Фаза 4: v1.0 (2-3 месяца)
- Стабилизация
- Полная документация
- Packaging для всех платформ

**Общая длительность до v1.0**: 10-16 месяцев

## 💡 Инновации

### 1. Metadata as Code
Задачи, документы, финансы в YAML-файлах, версионируемых в Git

### 2. Hybrid Storage
Git (версионирование) + SQL (быстрый поиск и реляции)

### 3. Zero-Knowledge Encryption
End-to-end шифрование критичных данных

### 4. Smart Conflict Resolution
Визуальное разрешение конфликтов с пониманием структуры YAML

### 5. Auto-Generated Reports
Еженедельные отчеты на основе Git-истории и метаданных

## 🎯 Кому подходит InGit?

### ✅ Идеально для:
- Фрилансеров и индивидуальных разработчиков
- Малых команд (2-20 человек)
- Домашнего использования (личный архив, финансы)
- Компаний, требующих контроль над данными
- Проектов с ограниченным интернетом

### ❌ Не подходит для:
- Крупных корпораций (1000+ пользователей)
- Проектов, требующих real-time collaboration 24/7
