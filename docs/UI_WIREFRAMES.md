## UI/UX Принципы

### Цветовая схема
- **Primary**: #1890ff (синий)
- **Success**: #52c41a (зеленый)
- **Warning**: #faad14 (желтый)
- **Error**: #f5222d (красный)
- **Text**: #262626 (темно-серый)
- **Background**: #ffffff (белый)
- **Secondary Background**: #f5f5f5 (светло-серый)

### Типографика
- **Headings**: Inter, sans-serif, Bold
- **Body**: Inter, sans-serif, Regular
- **Code**: Fira Code, monospace

### Icons
- Ant Design Icons
- Feather Icons
- Material Icons

### Responsive Breakpoints
- Desktop: > 1200px
- Tablet: 768px - 1200px
- Mobile: < 768px

## Keyboard Shortcuts

- `Ctrl+N`: New Task
- `Ctrl+P`: Command Palette
- `Ctrl+K`: Quick Search
- `Ctrl+S`: Save
- `Ctrl+Shift+P`: New Project
- `Ctrl+G`: Git Operations
- `Ctrl+/`: Toggle Sidebar
